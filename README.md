# Dentist Guide Vietnam

Static landing page for GitHub + Vercel.

Import repository into Vercel. Framework: Other. Build command: empty. Output directory: public. Production branch: main. Configuration is in vercel.json.

The consultation form is explicitly a local demo: no requests are sent or saved. No database, server credentials or patient data are included. The VPS package is separate and is not deployed by this project.

Custom domain: dentistguidevietnam.com; add in Vercel and apply the exact DNS values returned by the project.
